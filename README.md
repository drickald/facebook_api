## 📌 Project Overview

This repository contains a **Facebook API Project** created mainly using **CSS**.  
The project is set to **Public** and is intended for practice and academic purposes.

## 🧩 Technologies Used

- CSS

## 📂 Repository Information

- **Repository Name:** facebook_api  
- **Project Type:** Facebook API Project  
- **Visibility:** Public  

---

## 🚀 How to Clone the Repository

Follow the steps below to get a copy of this project on your local machine.

### 1️⃣ Open Git Bash or Terminal

### 2️⃣ Run the clone command

```bash
git clone https://github.com/drickald/facebook_api.git

```

3️⃣ Go to the project folder
```bash
cd facebook_api
```
▶️ How to Run the Project

Open the project folder

Open the main file (e.g. index.html) in your browser

Make sure CSS files are properly linked
